After the download

Three steps to a working mod.

  1. Check the file

    On Windows: certutil -hashfile autobuild-gui-<version>.jar SHA256, then compare it with the release page.

  2. Drop it into mods

    Together with Fabric API, MaLiLib, Litematica and Baritone — the full list is under Setup.

  3. Press B

    Enter a world and open the menu. Missing dependencies are named in the menu itself.

  4. Older versions

    Every build stays available under all releases.
